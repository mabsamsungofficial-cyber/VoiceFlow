APK BANANE KE STEPS (sirf browser chahiye, 5 minute):
1. github.com par free account banao -> New repository (naam: smart-voice-app).
2. "uploading an existing file" se is zip ke ANDAR ka saara content upload karo
   (.github folder samet - zip extract karke uske andar ki files/folders drag-drop).
3. Repository me "Actions" tab -> "Build APK" -> run hone do (3-5 min).
4. Run complete hone par neeche "Artifacts" me SmartVoiceInput-APK download karo,
   zip extract karo -> app-debug.apk phone me install karo (Unknown sources allow).
5. App kholo -> Settings -> apni Gemini API Key daalo (aistudio.google.com se free).
